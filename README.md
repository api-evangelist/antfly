Antfly provides a self‑learning retrieval engine for AI agents, enabling hybrid search over user‑owned data sources such as PostgreSQL, S3, and file systems. It offers built‑in vector embeddings, reranking, multimodal support (text, images, audio, video), and a knowledge graph, all running locally or in the Antfly Cloud. The platform is open‑source, free for self‑hosted use, and includes managed growth and enterprise plans with RBAC, SSO, autoscaling, and unlimited queries.

**Areas:** AI · Search · Retrieval · Vector · Hybrid

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Antfly: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
